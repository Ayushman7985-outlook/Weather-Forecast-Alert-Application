# 10. Screenshots / Outputs to Capture

Save in `images/` with these names:
1. `01_project_folder.png`: VS Code explorer showing the structure
2. `02_simulation_terminal.png`: `python main.py --mode simulation --city Varanasi`
3. `03_api_terminal.png`: API mode run (blur nothing sensitive; the key is not printed)
4. `04_current_weather.png`: CURRENT WEATHER section
5. `05_forecast_output.png`: daily forecast table
6. `06_alert_output.png`: storm or heatwave scenario with alerts
7. `07_csv_report.png`: a generated CSV opened in Excel
8. `08_chart.png`: `images/<city>_forecast.png`
9. `09_dashboard.png`: Streamlit dashboard
10. `10_github_repo.png`: repo home page with README

Do not capture your `.env` file, email addresses or API key.
